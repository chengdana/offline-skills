# POC测试报告评分标准详细说明

## 重要说明

### POC阶段特殊考虑

1. **行业分析深度要求**：POC阶段不要求深入的行业平均值对比、行业阈值等内容。行业分析主要关注行业特点（如季节性、账期特点、上下游关系、竞争格局等）的描述，不将缺少行业平均值作为不足项。

2. **交叉营销产品推荐**：不能简单说"笼统"，应该说"未根据企业具体经营特点、行业特性有针对性推荐"。

3. **报告合规性检查**：如果有"个别表述不规范"作为不足，应该改为"基本满足"，不要写"全部满足"。完全满足理论上不用写不足。

4. **打分原则**：如果有不足的，尽量稍微扣点分，变为"基本满足"。避免过多"全部满足"。

## 一、基础内容评分（36分）

### 1. 基础信息分析（8分）

**企业案例评分标准：**

检查要素：
- 企业基础信息（成立时间、注册资本、经营地址、法定代表人等）
- 股权结构分析
- 实际控制人识别
- 经营情况描述
- 行业分析
- 担保情况说明

评分档次：
- 全部满足或基本满足（6-8分）：包含5个以上关键要素，分析完整
- 部分满足（2-6分）：包含3-4个关键要素，部分维度缺失
- 少部分满足（0-2分）：包含1-2个关键要素，大部分维度缺失
- 完全不满足（0分）：缺少基础信息分析

**个人消费类案例评分标准：**

检查要素：
- 客户基本情况（姓名、年龄、职业等）
- 家庭情况（配偶、子女等）
- 收入情况
- 资债情况
- 注意：不需要经营情况分析

评分档次：
- 全部满足或基本满足（6-8分）：包含3个以上关键要素
- 部分满足（2-6分）：包含2个关键要素
- 少部分满足（0-2分）：包含1个关键要素
- 完全不满足（0分）：缺少基础信息分析

**个人经营类案例评分标准：**

检查要素：
- 客户基本情况
- 家庭情况
- 收入情况
- 资债情况
- 经营情况（必须包含）

评分档次：
- 全部满足或基本满足（6-8分）：包含4个以上关键要素，包括经营情况
- 部分满足（2-6分）：包含3个关键要素
- 少部分满足（0-2分）：包含1-2个关键要素
- 完全不满足（0分）：缺少基础信息分析

### 2. 财务分析（8分）

**仅适用于企业案例，个人案例不评分**

检查要素（五大维度）：
- 偿债能力分析（资产负债率、流动比率等）
- 盈利能力分析（净利润、利润率等）
- 营运能力分析（周转率等）
- 现金流分析
- 发展能力分析（增长率等）
- 财务健康度综合评估
- 主要财务风险点总结

评分档次：
- 全部满足或基本满足（6-8分）：包含5个以上维度，有综合评估和风险总结
- 部分满足（2-6分）：包含3-4个维度
- 少部分满足（0-2分）：包含1-2个维度
- 完全不满足（0分）：缺少财务分析

### 3. 征信分析（8分）

**企业案例评分标准：**

检查要素：
- 征信记录
- 不良情况
- 授用信情况
- 担保情况
- 工商信息
- 税务信息
- 司法信息
- 信用健康度综合评估
- 主要信用风险点总结

评分档次：
- 全部满足或基本满足（6-8分）：包含5个以上维度，有综合评估
- 部分满足（2-6分）：包含3-4个维度
- 少部分满足（0-2分）：包含1-2个维度
- 完全不满足（0分）：缺少征信分析

**个人案例评分标准：**

检查要素：
- 征信信息
- 不良记录
- 授用信情况
- 司法信息
- 信用评估

评分档次：
- 全部满足或基本满足（6-8分）：包含4个以上维度
- 部分满足（2-6分）：包含2-3个维度
- 少部分满足（0-2分）：包含1个维度
- 完全不满足（0分）：缺少征信分析

### 4. 流水分析（4分）

**企业案例评分标准：**

检查要素：
- 账户余额
- 借贷行为
- 资金流入流出构成
- 交叉营销产品推荐
- 流水健康度评估
- 主要经营风险点总结

评分档次：
- 全部满足或基本满足（3-4分）：包含4个以上维度
- 部分满足（2分）：包含2-3个维度
- 少部分满足（1分）：包含1个维度
- 完全不满足（0分）：缺少流水分析

**个人案例评分标准：**

检查要素：
- 流水分析
- 账户余额
- 资金收支
- 稳定性分析

评分档次：
- 全部满足或基本满足（3-4分）：包含3个以上维度
- 部分满足（2分）：包含2个维度
- 少部分满足（1分）：包含1个维度
- 完全不满足（0分）：缺少流水分析

### 5. 风险识别（8分）

**企业案例评分标准：**

检查要素：
- 涉诉信息
- 负面舆情
- 征信异常
- 财务指标恶化
- 关联交易风险
- 风险评估说明

评分档次：
- 全部满足或基本满足（6-8分）：包含4个以上风险维度，有评估说明
- 部分满足（2-6分）：包含2-3个风险维度
- 少部分满足（0-2分）：包含1个风险维度
- 完全不满足（0分）：缺少风险识别

**个人案例评分标准：**

检查要素：
- 风险分析
- 还款能力评估
- 稳定性分析
- 异常识别
- 风险评估

评分档次：
- 全部满足或基本满足（6-8分）：包含4个以上风险维度
- 部分满足（2-6分）：包含2-3个风险维度
- 少部分满足（0-2分）：包含1个风险维度
- 完全不满足（0分）：缺少风险识别

## 二、报告质量评分（30分）

### 6. 内容准确性（10分）

检查要点：
- 关键数据准确，核心指标准确
- 无明显逻辑或数据指标错误
- 无明显的大模型幻觉问题
- 生成报告泛化能力强
- 数据来源可追溯

评分档次：
- 全部满足或基本满足（7-10分）：数据准确，无明显错误
- 部分满足（4-7分）：大部分数据准确，有少量错误
- 少部分满足（0-3分）：数据准确性较差
- 完全不满足（0分）：数据错误严重

### 7. 模型推理质量（5分）

检查要点：
- 模型推理逻辑是否准确
- 推导是否清晰
- 无明显错误

评分档次：
- 全部满足或基本满足（3-5分）：推理准确，逻辑清晰
- 部分满足（1-3分）：推理基本准确，有少量问题
- 少部分满足（1分）：推理质量较差
- 完全不满足（0分）：推理错误严重

### 8. 分析深入度（10分）

检查要点：
- 生成的报告分析是否深入、有价值
- 是否充分分析关联关系（个人、企业等不同主体间）
- 是否洞察力强，能提供超出基础数据的业务提示
- 具备较好参考价值

评分档次：
- 全部满足或基本满足（7-10分）：分析深入，有价值，洞察力强
- 部分满足（4-7分）：分析有一定深度，但不够充分
- 少部分满足（0-3分）：分析停留在表面
- 完全不满足（0分）：缺少深入分析

### 9. 报告合规性检查（5分）

检查要点：
- 校验调查报告合规性
- 报告风格是否符合银行尽调报告文风风格要求
- 检查并反馈报告内容是否符合监管规定及行内制度要求

评分档次：
- 全部满足或基本满足（3-5分）：符合银行尽调报告要求，合规
- 部分满足（1-3分）：基本符合，有少量不规范
- 少部分满足（1分）：合规性较差
- 完全不满足（0分）：不符合合规要求

## 三、打分理由撰写规范

每个评分项的打分理由应包含：

1. **优点**：列举报告中做得好的地方，具体说明包含了哪些维度或要素
2. **不足**：指出报告中的不足之处，说明缺失或不够完善的维度

示例：
```
优点：包含完整的企业基础信息（成立时间、注册资本、经营地址等）、股权结构分析、实际控制人识别、经营情况描述、行业分析、担保情况说明
不足：行业舆情分析相对简略
```

## 四、总分计算

**企业案例**：
- 基础内容：36分
- 报告质量：30分
- 总分：66分

**个人案例**：
- 基础内容：28分（财务分析8分不计）
- 报告质量：30分
- 总分：58分
- 换算为66分制：(实际得分/58) × 66

## 五、总体评价撰写

在完成所有案例打分后，需要撰写总体评价，包括：

1. **优点总结**：列举厂商报告的主要优点（3-5条）
2. **不足总结**：列举厂商报告的主要不足（3-5条）
3. **建议**：针对不足提出改进建议（3-5条）
4. **评分汇总**：列出每个案例的得分和百分比
5. **平均分**：计算所有案例的平均分和平均百分比
