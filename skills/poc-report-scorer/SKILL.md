# POC测试报告打分工具

## 概述

本技能用于评估银行信贷调查报告智能化POC测试的厂商报告质量。支持企业案例和个人案例（消费类、经营类）的自动化打分和详细分析。

## 评分标准

### 评分维度

**基础内容（36分）**
1. 基础信息分析（8分）
2. 财务分析（8分）- 仅企业案例
3. 征信分析（8分）
4. 流水分析（4分）
5. 风险识别（8分）

**报告质量（30分）**
6. 内容准确性（10分）
7. 模型推理质量（5分）
8. 分析深入度（10分）
9. 报告合规性检查（5分）

### 案例类型差异

**企业案例**：
- 需要完整的财务分析（偿债、盈利、营运、现金流、发展能力五大维度）
- 需要经营情况、行业分析、股权结构等
- 满分66分

**个人消费类案例**：
- 不需要财务分析（企业财务报表）
- 不需要经营情况分析
- 需要客户基本情况、家庭情况、收入情况、资债情况
- 满分58分（财务分析8分不计）

**个人经营类案例**：
- 不需要财务分析（企业财务报表）
- 需要经营情况分析
- 需要客户基本情况、家庭情况、收入情况、资债情况、经营情况
- 满分58分（财务分析8分不计）

## 使用流程

### 1. 准备工作

确认以下信息：
- 厂商名称
- 案例列表（通常为5个：3个企业案例 + 2个个人案例）
- 报告文件路径（PDF格式）
- 输出目录（建议放在厂商文件夹中）

### 2. 执行打分

运行打分脚本：

```bash
python scripts/score_reports.py \
  --vendor "厂商名称" \
  --reports "案例1:类型:路径" "案例2:类型:路径" ... \
  --output "输出目录"
```

案例类型：
- `enterprise` - 企业案例
- `consumption` - 个人消费类
- `business` - 个人经营类

示例：
```bash
python scripts/score_reports.py \
  --vendor "阿里云飞天（杭州）云计算技术有限公司" \
  --reports \
    "沐欣-企业:enterprise:path/to/report1.pdf" \
    "钱超-消费:consumption:path/to/report4.pdf" \
  --output "e:\claudecode\POC测试结果(仅含报告)\阿里云飞天（杭州）云计算技术有限公司"
```

### 3. 输出文件

脚本会在输出目录生成：
1. `{厂商名称}_详细打分报告.txt` - 包含每个案例的详细打分理由和总体评价
2. `{厂商名称}_打分明细表.csv` - CSV格式的打分明细，可导入Excel

## 打分逻辑

详细的打分逻辑和评分标准请参考 `references/scoring-criteria.md`。

## 注意事项

1. **个人案例特殊处理**：个人案例不评估企业财务分析，该项标记为"不适用"，满分调整为58分
2. **案例类型识别**：必须正确标识案例类型（enterprise/consumption/business），否则打分标准会不准确
3. **文件路径**：所有输出文件放在厂商文件夹中，便于管理和查找
4. **打分理由**：每个评分项都需要包含优点和不足，确保打分有据可查
5. **总分换算**：个人案例的总分需要换算为66分制以便横向对比

## 快速开始

如果用户提供了报告路径列表，直接使用打分脚本。如果用户只提供了厂商文件夹，先扫描文件夹找到所有PDF报告，然后询问用户每个报告的案例类型。
