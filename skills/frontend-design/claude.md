# 前端设计 (Frontend Design) 使用说明

## 功能简介
设计前端用户界面，包括网页设计、组件设计、交互设计和视觉设计。

## 使用场景
- 需要设计网站或应用界面时
- 创建 UI 组件和设计系统时
- 规划用户交互流程时
- 需要视觉设计和样式指导时

## 快速开始
告诉 Claude 你的设计需求：
- "设计一个登录页面"
- "创建一个导航组件"
- "规划用户注册流程"

## 设计范围
- 网页布局设计
- UI 组件设计
- 交互流程设计
- 视觉样式设计
- 响应式设计
- 可访问性考虑

## 输出内容
- 设计说明文档
- HTML/CSS 代码示例
- 设计规范和指南
- 组件库文档
