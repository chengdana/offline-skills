此技能指导创建独特的、生产级的前端界面，避免通用的"AI 糟粕"美学。实现真正有效的代码，对美学细节和创意选择给予非凡的关注。

用户提供前端需求：要构建的组件、页面、应用程序或界面。他们可能包括关于目的、受众或技术约束的上下文。

## 设计思维

在编码之前，了解上下文并致力于大胆的美学方向：
- **目的**：此界面解决什么问题？谁使用它？
- **语气**：选择一个极端：野兽派极简主义、极大主义混乱、复古未来主义、有机/自然、豪华/精致、顽皮/玩具般、编辑/杂志、野兽派/原始、装饰艺术/几何、柔和/粉彩、工业/实用主义等。有太多口味可供选择。使用这些作为灵感，但设计一个真正符合美学方向的。
- **约束**：技术要求（框架、性能、可访问性）。
- **差异化**：什么让这令人难忘？人们会记住的一件事是什么？

**关键**：选择清晰的概念方向并精确执行。大胆的极大主义和精致的极简主义都有效 - 关键是意图性，而不是强度。

然后实现工作的代码（HTML/CSS/JS、React、Vue 等），它：
- 生产级和功能性
- 视觉上引人注目和难忘
- 与清晰的美学观点内聚
- 在每个细节上都精心完善

## 前端美学指南

专注于：
- **排版**：选择美丽、独特和有趣的字体。避免通用字体，如 Arial 和 Inter；选择提升前端美学的独特选择；意想不到、富有性格的字体选择。将独特的显示字体与精致的正文字体配对。
- **颜色和主题**：致力于内聚的美学。使用 CSS 变量保持一致性。带有鲜明强调的主导颜色优于胆小、均匀分布的调色板。
- **运动**：使用动画进行效果和微交互。优先使用仅 CSS 解决方案进行 HTML。在可用时使用 Motion 库进行 React。专注于高影响力时刻：一个精心编排的页面加载与交错显示（animation-delay）比分散的微交互创造更多愉悦。使用滚动触发和悬停状态来惊喜。
- **空间构图**：意想不到的布局。不对称。重叠。对角线流动。打破网格的元素。慷慨的负空间或受控的密度。
- **背景和视觉细节**：创造氛围和深度，而不是默认为纯色。添加匹配整体美学的上下文效果和纹理。应用创意形式，如渐变网格、噪声纹理、几何图案、分层透明度、戏剧性阴影、装饰边框、自定义光标和颗粒叠加。

从不使用通用的 AI 生成美学，如过度使用的字体系列（Inter、Roboto、Arial、系统字体）、陈词滥调的配色方案（特别是白色背景上的紫色渐变）、可预测的布局和组件模式，以及缺乏特定上下文角色的饼干切割器设计。

创造性地解释并做出感觉真正为上下文设计的意想不到的选择。任何设计都不应该相同。在浅色和深色主题、不同字体、不同美学之间变化。跨代从不收敛于常见选择（例如 Space Grotesk）。

**重要**：将实现复杂度与美学愿景匹配。极大主义设计需要带有广泛动画和效果的精心制作的代码。极简主义或精致的设计需要克制、精度和对间距、排版和微妙细节的仔细注意。优雅来自于很好地执行愿景。
