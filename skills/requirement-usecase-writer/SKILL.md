# Requirement Usecase Writer

Write structured requirement and use-case documents that are specific enough for implementation and review.

## Workflow

1. Clarify the business goal, user roles, and system boundary.
2. Define the use case with:
   - objective
   - trigger
   - actors
   - preconditions
   - main flow
   - alternate flows
   - postconditions
3. Add business rules, validation rules, and exception handling.
4. Make inputs, outputs, and dependencies explicit.
5. End with open questions or assumptions if any requirement is still ambiguous.

## Writing Rules

- Prefer concrete behavior over abstract intent.
- Separate business rules from UI details.
- Include edge cases that would affect implementation or approval.
- Avoid placeholder language once enough context exists.
