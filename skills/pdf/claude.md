# PDF 处理 (PDF) 使用说明

## 功能简介
处理 PDF 文件，包括读取、分析、提取内容和理解 PDF 文档。

## 使用场景
- 需要读取和分析 PDF 文档时
- 从 PDF 中提取文本或数据时
- 理解 PDF 文档内容和结构时
- 处理扫描的 PDF 文件时

## 快速开始
上传或提供 PDF 文件，告诉 Claude 你需要做什么：
- "分析这个 PDF 的内容"
- "提取这个报告的关键信息"
- "总结这个文档的要点"

## 支持的操作
- 读取 PDF 文本内容
- 提取表格和数据
- 分析文档结构
- 理解图文混合内容
- 总结关键信息

## 能力范围
- 文本提取
- 内容分析
- 信息摘要
- 数据提取
- 结构解析
