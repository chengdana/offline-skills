# 技能更新策略指南

本文档提供详细的技能更新策略和最佳实践。

## 描述优化策略

### 原描述不清晰时

改进要点：
- 增加明确的使用场景描述
- 说明核心功能和价值
- 添加适用对象（谁应该使用）
- 举例说明典型用例

**示例：**
```yaml
# 优化前
description: PPT 设计助手

# 优化后
description: 专业的 PPT 设计助手，使用苹果风格设计原则优化 HTML 演示文稿的排版、配色和布局。适合需要制作高质量演示文稿的用户
```

## 工作流程优化策略

### 流程步骤不清晰

改进要点：
- 使用数字编号标注步骤
- 每步骤包含：目标、方法、产出
- 标注关键决策点
- 补充遗漏的步骤

### 流程过于复杂

简化方法：
- 合并相似步骤
- 移除冗余操作
- 提炼核心主线
- 次要步骤标注为"可选"

**示例：**
```markdown
# 优化前
1. 分析文章
2. 生成标题
3. 生成配图

# 优化后
1. **接收和分析文章**
   - 提取核心观点、目标受众
   - 识别关键信息点（事实、数据、案例）
   - 产出：文章分析报告

2. **设计内容框架**
   - 确定目标人群和叙事风格
   - 设计文章结构（开头/主体/结尾）
   - 使用 AskUserQuestion 获取用户确认
   - 产出：已确认的内容框架

3. **生成完整内容**
   - 撰写正文（应用改写标准）
   - 生成 10 个标题供选择
   - 生成配图方案并执行
   - 产出：完整的公众号文章
```

## 质量标准优化策略

### 标准模糊

改进方向：
- 使用量化指标（数字、百分比）
- 提供可验证的检查点
- 增加正反例对比

### 检查项遗漏

补充方法：
- 从用户反馈中提取新检查点
- 参考行业最佳实践
- 覆盖常见错误场景

**示例：**
```markdown
# 优化前
- ✅ 内容质量好
- ✅ 格式正确

# 优化后
- ✅ 与原文重合率 < 20%（使用查重工具验证）
- ✅ 标题长度 15-25 字，包含情感词汇
- ✅ 配图数量 3-6 张，与内容高度相关
- ✅ 排版美观，移动端适配（max-width: 750px）
- ✅ 所有图片成功生成且无水印
- ✅ HTML 文件可直接在浏览器打开
```

## 功能扩展策略

### 新增功能点

实施步骤：
- 先在 "## 核心能力" 中概述
- 在 "## 工作流程" 中插入执行步骤
- 在 "## 质量标准" 中添加验证项
- 如需新工具，更新 `allowed-tools`

**示例：**
```markdown
# 在核心能力中新增
## 核心能力
- 深度分析原文并重新创作
- 生成咪蒙风格标题
- 自动生成 AI 配图
- **[新增] 自动查重并优化重复内容** ← 新功能

# 在工作流程中插入
6. **执行配图生成**
   ...

7. **[新增] 查重与去重优化**
   - 使用在线查重 API 检测重合率
   - 如重合率 > 20%，标记重复段落
   - 自动改写重复内容
   - 再次检测直至达标

8. **整合输出**
   ...

# 在质量标准中补充
- ✅ 与原文重合率 < 20%（已通过查重验证）
```

## 避免过度设计

### 过度设计的信号

- ❌ 超过 10 个一级章节
- ❌ 包含大量"未来扩展"内容
- ❌ 详细的理论说明和背景知识
- ❌ 重复的示例和说明
- ❌ 冗长的表格（超过 20 行）

### 保持简洁的方法

- ✅ 聚焦核心功能，一个技能解决一个问题
- ✅ 优先操作指导，减少理论说明
- ✅ 使用简洁的列表而非冗长的段落
- ✅ 示例精简，一个场景一个示例即可
- ✅ 将详细内容移至支持文件
