# PPT Designer

Improve presentation aesthetics with a clear, high-contrast, restrained visual style.

## Workflow

1. Identify the deck format and audience.
2. Simplify each slide to one core idea.
3. Improve:
   - hierarchy
   - spacing
   - alignment
   - color consistency
   - emphasis
4. Keep decorative elements secondary to the message.
5. Verify that every slide still reads clearly on a projector or laptop screen.

## Design Rules

- Prefer fewer elements with stronger hierarchy.
- Use consistent typography and spacing across slides.
- Avoid dense paragraphs; convert them into short bullets or visual groupings.
- Keep charts and tables readable before making them stylish.
