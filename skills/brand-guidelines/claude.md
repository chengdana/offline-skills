# 品牌指南 (Brand Guidelines) 使用说明

## 功能简介
这个技能提供 Anthropic 官方品牌色彩和排版规范，可以为任何需要 Anthropic 视觉风格的文档或工件应用官方品牌样式。

## 使用场景
- 需要创建符合 Anthropic 品牌规范的文档时
- 想要应用官方品牌颜色和字体时
- 创建演示文稿、文档或其他视觉内容时
- 需要保持品牌一致性时

## 快速开始
直接在创建文档或设计作品时调用此技能，它会自动应用：
- Anthropic 官方色彩方案
- Poppins 和 Lora 字体（或回退字体）
- 品牌标准的视觉样式

## 品牌色彩

### 主色
- 深色：`#141413` - 主要文本和深色背景
- 浅色：`#faf9f5` - 浅色背景和深色上的文本
- 中灰：`#b0aea5` - 次要元素
- 浅灰：`#e8e6dc` - 微妙背景

### 强调色
- 橙色：`#d97757` - 主要强调
- 蓝色：`#6a9bcc` - 次要强调
- 绿色：`#788c5d` - 第三强调

## 排版
- **标题**：Poppins 字体（回退到 Arial）
- **正文**：Lora 字体（回退到 Georgia）
- **注**：为获得最佳效果，建议在环境中预装这些字体
